# Red Carpet

해야 할 일이 몰리는 대학생이 지인과 약속을 잡을 때, 마감 뒤에 숨은 중간 단계까지 합친 날짜별 부하를 보고 진짜 여유 있는 날을 고를 수 있게 한다.

- 데모: https://tansan7271.github.io/vibe-coding-kimdogyun/
- 저장소: https://github.com/tansan7271/vibe-coding-kimdogyun

## 실행

브라우저에서 바로 열리는 정적 웹이다. 서버, 빌드, 설치가 없다.

- 배포된 주소를 열거나, 저장소를 받아 `index.html`을 더블클릭한다.
- 데이터는 이 브라우저의 localStorage에만 저장된다. 설정 화면에서 JSON 파일로 내보내고 가져올 수 있다.
- "데모 모드"를 켜면 허구의 예시 데이터로 전체 기능을 볼 수 있다. 내 데이터는 건드리지 않는다.

## 무엇을 하나

1. 할 일(마감)과 그 아래 중간 단계(부하 1~5, 예상 시간)를 넣는다. 수업·알바 같은 고정 일정도 넣는다(매주·격주·매월 반복).
2. 배치 규칙이 중간 단계를 마감 전 날짜에 깐다. 날마다 부하 예산과 안전선, 남은 시간을 넘지 않게.
3. 주간 카펫에서 날짜별 부하가 처짐으로 보인다. 상자(일정·단계)가 떨어져 쌓이고 카펫이 무게만큼 눌린다. 완료, 이 날 안 함(밀림), 끌어서 다른 날에 고정.
4. (선택) 과제 요건 같은 글을 붙여넣으면 Claude API가 중간 단계 초안을 만든다. 사용자 본인의 API 키가 필요하고, 키는 어디에도 저장하지 않는다(메모리에만).

자세한 규칙은 `SPEC.md`, 작업 규칙은 `CLAUDE.md`.

## 테스트

```
node --test
```

배치 규칙, 카펫 모양, 롤, 물리, 데이터 검사, AI 응답 검사 등 순수 함수 모듈의 테스트. 설치 없이 Node만 있으면 된다.

## 폴더

- `phase0/`: 과제 Phase 0(나이브 베이스라인)의 결과물. 참고용이며 앱과 무관하다.
- 나머지 파일 구성은 `CLAUDE.md`의 "저장소 구조".
